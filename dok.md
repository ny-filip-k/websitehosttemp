# Dokumentation – Auftrag 2: Mediensammlung mit HTML und CSS Grid


---

# 1. Projektbeschreibung

Im Rahmen dieses Auftrags wurde eine Webseite erstellt, welche eine persönliche Filmsammlung präsentiert. Die Filme werden in einem übersichtlichen Grid-Layout dargestellt und enthalten jeweils ein Coverbild, den Titel, das Erscheinungsjahr sowie einen Link zu einem externen Streaming-Angebot.

Das Design orientiert sich an modernen Streaming-Plattformen und wurde bewusst einfach und benutzerfreundlich (definitiv nicht weil das einfacher als anderer design war) gestaltet. Ziel war es, die erlernten HTML- und CSS-Techniken praktisch anzuwenden und eine optisch ansprechende Webseite zu erstellen.

---

# 2. Zielsetzung

Folgende Ziele sollten erreicht werden:

* Erstellung einer Wireframe-Skizze
* Aufbau einer semantisch korrekten HTML-Seite
* Verwendung von HTML-Containern zur Strukturierung
* Umsetzung eines CSS-Grid-Layouts
* Darstellung von Coverbild, Titel und Erscheinungsjahr
* Verlinkung auf externe Angebote
* Veröffentlichung der Webseite auf einem Webserver

---

# 3. Anwendung des IPERKA-Modells

## I – Informieren

Zu Beginn wurde die Aufgabenstellung genau gelesen und analysiert. Dabei wurden die Anforderungen an die Webseite sowie die Bewertungskriterien betrachtet.

Zusätzlich wurden die Lerninhalte zu HTML, CSS und CSS Grid wiederholt. Mithilfe von Beispielen konnte ein besseres Verständnis für den Aufbau eines Grid-Layouts gewonnen werden.

---

## P – Planen

Nach der Analyse wurde ein Wireframe erstellt. Dieses diente als Grundlage für die spätere Umsetzung.

Im Wireframe wurden folgende Bereiche geplant:

* Seitentitel
* Hauptbereich mit Filmkarten
* Anordnung der Filme in einem Raster
* Positionierung von Bild, Titel, Jahr und Link

Durch die Planung konnte bereits vor der Umsetzung eine klare Struktur festgelegt werden.


---

## E – Entscheiden

In dieser Phase wurden verschiedene Designmöglichkeiten verglichen.

Es wurde entschieden:

* Eine Filmsammlung zu erstellen
* Ein dunkles Farbschema zu verwenden
* CSS Grid für die Darstellung einzusetzen
* Die Inhalte mittig auf der Seite anzuordnen
* Hover-Effekte für ein moderneres Erscheinungsbild einzubauen


---

## R – Realisieren

Die Umsetzung erfolgte mit HTML und CSS.

Zuerst wurde die Grundstruktur mit semantischen HTML-Elementen erstellt:

* header
* main
* article

Anschliessend wurden die Filmdaten eingefügt. Jede Filmkarte enthält:

* Coverbild
* Filmtitel
* Erscheinungsjahr
* Externen Link

Danach wurde das Layout mit CSS gestaltet. Für die Anordnung der Karten wurde CSS Grid verwendet. Zusätzlich wurden Farben, Abstände, Schriftgrössen und Hover-Effekte definiert.

---

## K – Kontrollieren

Nach der Fertigstellung wurde die Webseite getestet.

Folgende Punkte wurden überprüft:

* Funktionieren alle Links?
* Werden alle Bilder korrekt angezeigt?
* Ist das Grid korrekt ausgerichtet?
* Sind die Inhalte gut lesbar?
* Werden die Hover-Effekte angezeigt?


---

## A – Auswerten

Durch dieses Projekt konnten die Kenntnisse im Bereich HTML und CSS erweitert werden.

Besonders hilfreich war:

* Die Planung mittels Wireframe (also es wär bei grösserem Projekt hilfreich, bei so einem kleinem Umsetzung konnte ich theorethisch ohne dem arbeiten)
* Die Arbeit mit CSS Grid
* Die Verwendung semantischer HTML-Elemente

Die gesetzten Ziele konnten erreicht und die Anforderungen erfolgreich umgesetzt werden.
